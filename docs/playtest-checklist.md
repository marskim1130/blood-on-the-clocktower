# 手机面杀验收清单

本项目当前定位为真人说书人主持的同桌辅助工具。H5/微信负责同步与私密操作，讨论、闭眼和特殊规则裁定在线下完成；不是无人主持的全自动游戏。

## 页面与流程

| 页面 | 已接入功能 |
| --- | --- |
| 大厅 | 昵称、创建、房间号加入、邀请链接进入、恢复身份、连接反馈 |
| 准备 | 成员列表、说书人、顺时针座位、准备、角色配置、恶魔伪装、私密身份确认、开始 |
| 对局：玩家 | 自己的身份、夜间选择/等待审核/按住结果/已阅、间谍私密魔典、守鸦人死亡触发、提名、控辩倒计时、逐席投票、幽灵票 |
| 对局：说书人 | 私密魔典、夜间审核与代办/跳过、黎明死亡确认、计时暂停/继续、代投、日终处决、胜负裁定、私密操作日志与撤销/重做 |
| 结算 | 胜负、说书人确认揭幕、死亡与提名汇总、同房再开 |
| 剧本 | 暗流涌动角色查询与配置辅助 |
| 房内公共入口 | 保存私人恢复码、设备恢复审批（仅审批者）、连接状态、房主关闭房间 |

页面划分是针对本项目的设计，不代表照搬其他应用。参考：[官方规则说明](https://wiki.bloodontheclocktower.com/Rules_Explanation)、[阿瓦隆发行方介绍](https://indieboardsandcards.com/our-games/the-resistance-avalon/)；狼人杀/阿瓦隆仅作为同桌产品流程参考，本仓库没有实现这两个游戏。

## 必须保留的测试路径

1. 房主创建，其他设备加入；指定说书人、全员准备、分配合法角色、每人确认后才能开局。
2. 无关玩家看不到其他人的夜间步骤、目标、角色、死因与裁定；结果查看后仍需已阅才能推进。
3. 玩家夜间提交，说书人确认或修改；全部夜间步骤完成后生成建议，确认零人或多人死亡才天亮。
4. 提名后控方/辩方/顺时针投票；最后一位为被提名人。死者反对不消耗幽灵票，赞成才消耗。
5. 达到门槛的唯一最高票候选在日终处决；最高票并列不处决。
6. 胜负确定不自动公开全身份；说书人揭幕后全员可见，再开清空本局秘密并保留成员座位。
7. 同设备刷新恢复原身份；跨设备导入 CT3 独立恢复码，等待说书人审批，批准前不得收到身份/私密投影或替换旧连接。批准后原子轮换凭据，旧设备退出。无效凭据、非审批人及自批均拒绝。
8. 持久化写入失败不能广播成功或推进游戏；重复命令不能重复执行。
9. 恢复申请同意/拒绝均为终态，重放同一批准不再踢掉新设备。批准丢包后十分钟内可凭原请求与恢复码重取结果，包含服务端重启；等待页刷新后重贴同码复用本机非秘密请求票据。
10. 说书人撤销/重做只恢复游戏状态及成员锁定标记，不回滚成员、身份凭据、命令序列。跨阶段需二次确认；投票计时恢复后默认暂停；已经展示给人的信息无法真正收回。

## 验证边界与待办

- 自动化覆盖核心、状态管理、Go 领域、权限隔离和 WebSocket 对局流程；构建通过不等于微信真机验收。
- 公网 HTTPS/WSS、微信合法域名与真机、Docker/Redis/Caddy 容器联调仍需部署环境验证。当前本地浏览器验收服务使用临时内存存储。
- 恢复说书人本人时由房主审批；若申请人也是唯一审批人，必须先在原设备指定其他说书人或转移房主，系统不会允许自批。旧设备彻底丢失且没有其他审批者时，需要管理员人工处理，不能绕过审批。
- CT2 旧恢复码不得用于新恢复入口。历史上已经导出的直接登录凭据只能通过批准换设备轮换或重建房间撤销；不要将旧版本凭据当作安全的新恢复码分享。
- 操作历史最多撤回30步、保留100条说书人私密日志；成员/座位/说书人变更及重赛建立新历史边界，不支持跨成员变动回滚。
- 七天不活跃清理按最后成功持久化写入计算；在线连接、只读刷新不续期。启动及每小时检查，超过七天才删除，旧记录先安全补时间戳获得完整宽限期；持久删除失败保留房间。
- 守鸦人死亡名单锁定后，完成私密选择/审核/已阅再统一天亮；真人说书人仍负责特殊注册、中毒假信息及特殊胜负裁定，不是无人主持的全自动规则引擎。
- 投票计时由说书人前台触发到期请求，服务器核验期限与当前阶段；说书人离线时不保证自动持续推进。
- 无震动、无自动音效。未验证 React Native。
- 仓库许可证不代表已获得第三方游戏内容授权；本轮没有执行开源发布或公网部署。

## 本地复验命令

本轮已完成前端/核心测试、Go 全量与并发检测、TypeScript 编译、协议漂移检查、H5 和微信构建。H5 仅有包体积提示。390×844 浏览器实测覆盖创建、指定说书人、另一端加入、准备/取消、刷新恢复和恢复码遮罩；完整夜间至再开流程由 WebSocket 自动化覆盖，不冒充所有环节的手机真机测试。最终测试数量与新增三端审批实测结果以 work.md 最新验收记录为准。

最终自动化：22 个前端/核心测试文件、255 条测试通过；Go `-race` 全通过，类型/协议/补丁检查通过。三独立浏览器来源实际验证：准备状态撤销/重做同步，CT3 复制提示与主动显示，待审批刷新重贴、说书人批准、新设备保留座位、旧设备退出、新恢复码轮换，恢复码30秒后自动从页面移除。最终微信构建5.90秒无警告，H5构建9.82秒仅体积提示。

node scripts/generate-protocol-contracts.mjs --check
