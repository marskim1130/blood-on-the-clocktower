# 手机面杀界面规范

本轮只调整展示、布局与页面局部状态，不改游戏协议或服务器权威规则。

## 视觉方向

参考[血染钟楼官网](https://bloodontheclocktower.com/)的哥特氛围、复古衬线标题与深浅材质对照；配色为本项目重新选定，并非复制官网样式代码。钟楼装饰使用原创 CSS 几何图形，没有下载官方图片、标志或字体。

| 设计变量 | 颜色 | 用途 |
| --- | --- | --- |
| ink | `#120c1c` | 紫黑页面背景 |
| paper | `#eee1c5` | 羊皮纸色、标题与入局卡 |
| wine | `#7a2539` | 血红主操作 |
| gold | `#b99b61` | 古金分隔、选中状态与序号 |

中文标题使用本机宋体/衬线字体回退，正文使用系统无衬线字体。按钮同时使用文字、边框与颜色区分状态，不仅靠颜色传达。

## 布局

借鉴 [Board Game Arena 移动端指南](https://en.doc.boardgamearena.com/Your_game_mobile_version)与[官方 UX 指引](https://en.doc.boardgamearena.com/images/5/57/Guidelines_UX_new_compressed.pdf)的当前行动优先与窄屏重排原则，不通过整体缩小桌面页面适配手机。

- 公共框架：紧凑顶栏、固定高度滚动区、底部主桌/图鉴/记录/更多。页面主要操作独立固定在导航上方。
- 大厅：共享昵称、创建/加入切换、剧本介绍。邀请只预填与切换，不自动加入。
- 准备：下一步与人数概况、座位/配角/房间设置。成员管理不再占用默认主桌。
- 对局：当前阶段与行动优先；座位和说书人管理为独立分区。完整夜序不遮挡当下行动。
- 图鉴：角色搜索/分类、夜序与人数规则分区。
- 结算：胜负与身份卡优先，详细时间线折叠。
- 记录：公开事件与说书人私密日志。更多：设备恢复/审批、隐私说明与开发工具。

桌面使用居中的主次栏，窄屏改纵向布局。普通触控按钮至少44px；保留底部安全区。Taro 4 ScrollView 需要明确高度，不能仅靠内容撑高导致内外双滚动。

## 不得回归

- 不移除长按查看、水印、松手/后台/30秒隐藏及恢复审批。
- 不以布局切换自动提交准备、投票、配角或夜间选择。
- 隐藏管理入口不等于权限控制，服务端校验保持不变。
- 不重新堆叠多套全局主题覆盖；通用座位、标签和按钮样式在 app.css 维护，页面只保留专属布局。
- Taro H5 可能出现 `disabled="false"`，禁用态选择器不得把可用按钮灰化。
- 弹窗确认文案最长4字；布局变更后仍需双端构建、窄屏截图和交互回归。
