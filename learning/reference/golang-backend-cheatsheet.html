Go 与本项目后端速查表

用途：从 Taro 前端的一个 WebSocket 操作，快速定位 Go 后端应该阅读的模块。

Go 最小语法

struct
数据组合，例如 session.Actor。
方法 [method]
func (s *Session) Execute(...)；括号里的值是接收者 [receiver]。
接口 [interface]
只描述行为，例如 RoomRecordStore 的 Create/Replace/Delete。
错误 [error]
显式返回：value, err := call()；用 errors.Is 判断错误类别。
指针 [pointer]
*Session 表示指向对象，方法可修改对象或避免复制。
切片/映射 [slice/map]
动态列表与键值表；共享时要考虑复制和并发保护。

本项目模块地图

cmd/server/main.go             启动 HTTP/WebSocket 服务
internal/ws                    JSON 协议、连接、错误码、投影投递
internal/session                房间权威状态、凭证、序号、事务边界
internal/gameplay               游戏阶段、角色能力、胜负规则
internal/game                   领域类型、脚本、角色
internal/sessionstore            内存、文件、Redis 房间快照

命令提交模板

current := committed.Load()
candidate := clone(current)
if err := validate(candidate, actor, command); err != nil { return err }
apply(candidate, command)
if err := store.Replace(ctx, currentRevision, candidate); err != nil { return err }
committed.Store(candidate)
broadcast(projectForEachRecipient(candidate))

这不是通用框架，而是本仓库的核心阅读模型：先验证和构造候选状态，持久化成功后再发布。

调试入口

  • 连接没建立：Hub.HandleWebSocket、前端 TaroWebSocketTransport。
  • 协议错误：handleMessageV2、sendV2Error、proto/game.proto。
  • 权限/凭证/序号：AuthoritativeGameSession.ExecuteObserved。
  • 规则错误：GameSession.Apply 及对应 *_test.go。
  • 状态泄漏：GameSession.ProjectionFor。
  • 重启丢状态：sessionstore、启动时的 Registry.Restore。
